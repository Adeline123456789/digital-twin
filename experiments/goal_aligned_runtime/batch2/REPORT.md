## 接触诊断的新证据

1. 同行记录的关节目标/反馈经原机器人FK计算：两条真机对齐末段位置差分别约0.91mm、0.66mm，转角差不超过0.151°、0.145°。这是编码器与模型计算，并非外部测得的末端准确度；不能排除整体标定误差。
2. 仿真抓取到对齐的插头在夹爪内平移约2.21mm/2.36mm，转角约0.12°/0.52°。新`grasp_relation`输出已接入原`inspect_contact`工具，实际经EpisodeTools对两个Episode共8个状态调用，防止把“仍有接触”误写成“没有指间运动”。
3. 静态反事实检查：保留仿真插头位姿，只将手指开度换成同阶段真实编码器反馈。两条数据的grasp/lift/align共6点，原4–6个有效手指接触全部消失。该检查零物理推进、2.23秒。它支持“当前开度—几何—持物姿态组合不一致”，**不能单独判定摩擦、几何或开度标定是根因**。仿真插头位姿不是实测前提必须保留。
4. 复用已有CAD手指轮廓拟合，固定相机/几何，数值搜索±3mm开度偏置：原相机在两个独立第二条视图均退化，拒绝。使用历史光学朝向候选后图像重叠改善，但偏置达到边界且相机/几何/开度仍混淆，仍不接受为物理标定，不改XML或真实控制。

`tracking_diagnosis.json`、`real_aperture_contact_probe.json`、`grasp_relation_comparison.json`和两个aperture拟合报告保留输入、假设和结果。当前没有接受MuJoCo物理参数校准；16mm修复也因真机失败而拒绝。
