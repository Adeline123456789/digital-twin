## 从具体失败到源码修改

先前学生复测直接 STOP，预留 parent 声称工具不可用；教学程序即便执行修复，也在一次执行后返回，没有让学生依据该执行结果继续选择。实际 Agent 则有另一份重试逻辑。不能据此把问题全部归因于学生能力。

- `bounded_tools.explore` 现在统一教学与 `agent_loop --planner-policy bounded_tools_v1`：当前实际摘要/参数 → 学生选择检查或一变量实验 → 原采集程序执行 → 实际反馈交回学生。原先预测、实际结果和前次参数一起保留；累计扣减模型/工具/执行预算。
- 教师反馈包含学生各次决策及物理结果，教师不能在此执行循环内接管。初始化摘要直接来自已有数据工具；不是教师预先给修复答案。明确仿真特权信息可用于仿真假设实验，UNKNOWN 真实根因不自动否决仿真探索。
- 成功仿真产生 `pending_real_comparisons`，不自动运动或标记真实成功。保留原速度、动作生成、碰撞、滑移与独立成功判断。未执行时 `task_success=null`，不再写成测得的仿真失败。
- 三条既有 Episode 被不相关的真实录制导出器改动错误失效。现在仅排除已核实不被仿真调用的两个真实导出文件，仍核验其他源码；三条现有记录及“真实导出可变、仿真程序不可变”回归通过。这是局部依赖修正，不代表已完成场景变化适配。

默认仍是 `llm`。候选需新的同预算模型/物理对照后才能晋升；这次不是完整自进化，不声称 Token、成功率或成本改善。

## 使用的前人方法和边界

- [RHD §3.2–3.4](https://arxiv.org/html/2609.33378)：原问题是弱接收方如何应用冻结 VLA 的干预经验。采用“学生实际干预及结果→指导修订→学生再行动”，落到共享执行循环和全步骤教师反馈。原 VLA/注意力干预不适用于当前确定性 Piper 程序，没有安装或声称复现一个现成 RHD 包。
- [VISTA §3.3–3.4](https://arxiv.org/html/2610.35051)：原问题是通过主动环境探测改善可执行 harness，再冻结独立比较。核查 Apache-2.0 发布的 [capability 合同](https://github.com/AgenticEI/VISTA/blob/62eab4e6c4d6b413a7a8d653fe6e9ba1f5c50486/rpent/harness/contracts.py)、[LIBERO 行动后返回观测接口](https://github.com/AgenticEI/VISTA/blob/62eab4e6c4d6b413a7a8d653fe6e9ba1f5c50486/robots/libero/harness_adapter.py)、[选择逻辑](https://github.com/AgenticEI/VISTA/blob/62eab4e6c4d6b413a7a8d653fe6e9ba1f5c50486/meta_harness/selection.py)。复用机制，继续调用现有 Piper collector；没有移植 LIBERO、RGB-D/VLA 工具或拷贝框架源码。未采用其 minimum-token-spend gate，因为本项目目标是降低成本。
