# Method and limits

The bounded known-board fit reuses the installed FK-constrained reprojection implementation described and source-reviewed in [cycle6](../spatial_cycle6/METHOD.md), based on [SHECAR](https://robotics.shanghaitech.edu.cn/sites/default/files/papers/hand-eye_calibration_web.pdf). Unlike the earlier free-landmark fit, the88 grid points remain a rigid20mm board; only its6D pose and the6D wrist-camera mount are optimized. Existing OpenCV undistortion and SciPy bounded soft-L1 least squares are used. Intrinsics, nominal FK, physical parameters and heldout split stay fixed. The candidate is not deployed. Same-session repeated heldout use is explicitly disclosed.

Current real localization follows the existing native same-command observation path. Only an optional center_only view selector was added to avoid unsolicited joint sweeps; four focused poses are simulated at the original100Hz,12deg/s target profile and0.2mm penetration gate, with additional rejection of robot/task contact. No lower-level controller was replaced. Camera-trigger startup is handled by continuous native recording before execution; the fresh-frame guard and before-enable checks remain. Four relevant tests pass, including unchanged open-gripper/speed/fold behavior and rejecting altered/unvalidated references.

Current matched-pose RGB uses only this cycle's new measured joints and RGB exposures. Color/gray component locations are scene-specific diagnostics with threshold sensitivity, not general 3D perception or success detection. No RGB-D, measured six-axis force, expert-arm trajectories or historical real object poses enter this localization evidence.
