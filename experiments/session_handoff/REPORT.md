## 执行入口核查

使用第 3 轮实际入口和存档参考。以桩对象替换连接器，模拟连接前拦截并阻断 CAN/Piper 模块导入。只写临时采集目录，控制器和默认配置沿用原版本。

| 输入 | 模拟结果 |
| --- | --- |
| 默认 dry-run | 返回零硬件命令，未构造硬件对象 |
| 同一采集目录已有命令 CSV | 独占创建失败，旧 CSV 完整，未到达模拟连接 |
| 重复相同参考但换目录，或目录只有旧 START | 到达模拟连接边界，缺少跨目录请求去重和未确认结果检查 |
| 更改测试场景 YAML，同时保留原参考和原轨迹 | 到达模拟连接边界，缺少参考与场景版本绑定 |
| 指定未通过物理仿真的冻结参考 | 在构造硬件对象之前拒绝 |
| 省略冻结参考 | 旧的重采样分支到达模拟连接边界 |

这些结果对应被测入口。将来如果恢复执行，应先解决请求身份、场景版本和冻结参考的缺口，并重新走原有授权和安全检查。当前检查点禁止执行。
