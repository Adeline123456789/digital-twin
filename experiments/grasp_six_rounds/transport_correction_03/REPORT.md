# 垂直搬运候选：真实搬运未执行

保留抓取前缀，取消5度预倾的笛卡尔搬运候选通过原IK和接触界限，仿真最大倾角0.173度；抓取相对位移/转角也验证。

真机在lift结束由新增筛查拒绝：45.2→40.0mm，5.2mm越过5mm门槛；RGB顶部仅变化3px，未见之前的明显翻转。命令日志证实没有transport目标，随后直接折回、自动下使能。此结果是筛查拒绝，不是确认滑移，也不是垂直搬运验证成功。门槛混合了0.3→1Nm主动收紧与抬升扰动的影响，不能算已验证的故障预防收益。

数据双RGB各1226帧，原生导出/验证通过，命令40.89秒，全部电机/夹爪下使能独立确认。原日志误用通用insertion slip字样，真实事件由execution_report和本报告限定。

下一项仅在原位先建立1Nm保持，再以同一保持状态作为抬升比较基线；不放宽5mm/15px阈值，不执行插接。初始绝对夹持姿态仍需要独立观察。
