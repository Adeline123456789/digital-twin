The reviewer used a fresh context, no model backend or hardware, and no write authority. The first pass reproduced five issues. Path aliases crossed the split, overlapping manifest keys could hide an incorrect digest, an arbitrary rollback string was accepted, raw evidence was pinned too late, and the stream assumed 30 Hz. The reviewer also identified a bookkeeping bug that would close simulation starts at zero.

The final gate checks canonical paths, episode and trajectory identity, every independent digest, and a real Git rollback object with the expected active bytes. New pinned recorder inputs come from existing verification records. Two distinct held-out original trajectories were reserved for the updated gate. Positive and negative decisions and their active-file hashes are recorded in decisions.jsonl. Older P3.4 decisions reproduce at that round's commit; the P4.2 decisions supersede them.

The second pass confirmed the two acquired recordings, repeated-source refusal and the actual source-locked accept/reject outcomes. The reviewer independently counted only six different trajectory hashes across ten records, four among the six historical success controls. The paired report now discloses duplicates and leaves the population interval unknown. The reviewer reproduced a batch-only alarm on a two-lift fixture. The supervisor now requires agreement in both directions for retention kind, frame, first-observed time and confirmation time. The main agent tested these final disagreement cases.
